# Tarea Práctica: Crear una función basada en un problema de la vida real

**Estudiante:** Andrea Elizabeth Fernández Barragán

## Problema resuelto

Este programa permite calcular el promedio de dos notas ingresadas por el usuario.

## Función utilizada

La función `calcular_promedio(nota1, nota2)` recibe dos parámetros, realiza el cálculo del promedio y devuelve el resultado mediante `return`.

## Ejemplo

Ingrese la primera nota: 8

Ingrese la segunda nota: 10

Resultado: 9.0
